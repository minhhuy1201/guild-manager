Redesign this existing guild management application.

The product is used to manage a guild for Nghịch Thuỷ Hàn,
a Chinese wuxia MMORPG.

IMPORTANT:
The design should be minimal and modern.

Do NOT create an overly decorative wuxia or xianxia interface.

The application should feel primarily like a modern,
premium management product with subtle wuxia identity.

Design balance:

85% Minimal modern application
10% Subtle Chinese wuxia atmosphere
5% Nghịch Thuỷ Hàn identity

Visual direction:

- Clean layouts
- Strong visual hierarchy
- Generous spacing
- Minimal color palette
- Neutral surfaces
- Thin borders
- Subtle jade or muted green as the primary accent
- Soft antique gold only for important highlights
- Modern, readable typography

Use wuxia inspiration subtly through:

- Naming and terminology
- Small decorative details
- Iconography
- Color accents
- Selected states
- Section dividers

Avoid:

- Heavy Chinese patterns
- Dragons and fantasy artwork
- Large background illustrations
- Ink painting backgrounds
- Excessive gold decorations
- Calligraphy fonts for UI text
- Particle effects
- Clouds and mist effects
- Game-like HUD interfaces
- Excessive animations

The design should feel like:

"A premium, minimal guild management application
with a subtle wuxia soul."

Prioritize usability and information clarity over immersion.

This is an existing application.
Do not change business logic, API contracts, routes,
authentication, or existing functionality.
